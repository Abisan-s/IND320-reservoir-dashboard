# IND320 Reservoir Dashboard

This repository contains my project work for the course IND320

The project is developed through several parts and combines data collection, data processing, databases, analysis and visualization.

Lastly updated: 08.11.2026

## Project structure

- `app.py` - main Streamlit application
- `pages/` - the Streamlit pages
- `notebooks/` - Jupyter notebooks for the different project parts
- `data/` - local data files used in the project
- `requirements.txt` - Python dependencies

## Project parts

### Part 1
Initial reservoir dashboard using reservoir statistics data and Streamlit.

### Part 2
Extended the project with:
- NVE Magasinstatistikk API
- ENTSO-E API
- Cassandra
- Apache Spark
- MongoDB
- Cross-border electricity transfer visualizations

### Part 3

## Streamlit application

The project includes an interactive Streamlit dashboard where reservoir data, electricity transfer data and later weather analysis can be explored.
